# Abhishek-Kumar-Rai5.github.io

Personal site, built with [Jekyll](https://jekyllrb.com/) + the `minima` theme and published via GitHub Pages.

Live at **https://abhishek-kumar-rai5.github.io/**

Posts live under [`_posts/`](_posts/); the site config is [`_config.yml`](_config.yml). GitHub builds and deploys on
every push to `main` — no separate build step needed.
